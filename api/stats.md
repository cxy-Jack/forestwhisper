# 模块：统计（Stats）

Base Path: `/api/v1/admin/stats`

## 1. 仪表盘统计
- Path: `GET /api/v1/admin/stats/dashboard`
- Auth: 公开（或管理员）

## 2. 用户统计
- Path: `GET /api/v1/admin/stats/users`
- Auth: 公开（或管理员）

## 3. 内容统计
- Path: `GET /api/v1/admin/stats/contents`
- Auth: 公开（或管理员）

## 4. 评论统计
- Path: `GET /api/v1/admin/stats/comments`
- Auth: 公开（或管理员）

## 5. 趋势统计
- Path: `GET /api/v1/admin/stats/trend`
- Auth: 公开（或管理员）
