# 他人即地狱，是如何摧毁一个人的行动力的
“他人即地狱”，萨特在《禁闭》中写下的这句名言，曾被无数人误解为“人与人之间只能是相互折磨”。但真正的内核，从来不是否定人际关系的价值，而是揭示了一个残酷的真相：当我们过度被他人的评价、期待、否定所捆绑，把他人的目光当作衡量自我的唯一标尺时，自我的边界会被不断侵蚀，行动力会被一点点瓦解，最终在无尽的内耗中，陷入躺平摆烂的困境——这不是懒惰，而是长期被“他人地狱”驯化后，一种被动的自我保护与精神耗竭。

很多人都有过这样的经历：想开始一项新事业，却先想到“别人会不会觉得我不自量力”；想坚持一个爱好，却因为“别人说这没用”而半途而废；哪怕只是做好了一件小事，也会因为他人一句轻描淡写的“也就那样”，瞬间失去所有成就感。久而久之，我们不再敢尝试、不再愿坚持，不是能力不足，而是“他人即地狱”所催生的心理内耗，彻底摧毁了我们的行动力。从心理学角度来看，这种摧毁从来都不是一蹴而就的，而是通过三个核心环节，逐步瓦解我们的心理防线与行动意愿。

第一个环节，是**他人评价的“投射性认同”，瓦解自我价值感**。心理学中的“投射性认同”，指的是我们会不自觉地接收他人对我们的评价，并将其内化为自我认知。当他人不断否定我们（“你不行”“你做不到”“你太普通了”），或者用过高的期待绑架我们（“你必须做到最好”“你不能让我们失望”），我们会慢慢相信这些评价是真的——我们开始怀疑自己的能力，否定自己的价值，甚至觉得“我无论怎么做，都达不到别人的要求”。

这种自我价值感的崩塌，是行动力丧失的根源。行动力的本质，是“相信自己能做到”的底气，而当“他人即地狱”成为常态，我们的底气会被不断消耗：做一件事之前，先预设“会被否定”，于是不敢开始；做的过程中，一旦听到负面评价，就立刻放弃；哪怕做好了，也会因为“别人可能不认可”而否定自己的努力。就像一株被不断否定的小苗，原本的生长力会被一点点扼杀，最终只能枯萎——我们不再愿意付出努力，因为潜意识里已经认定，“努力也没用，只会被他人挑剔”。

第二个环节，是**“比较内耗”引发的心理疲惫，耗尽行动能量**。“他人即地狱”的另一种表现，是我们陷入了无休无止的“社会比较”。我们会不自觉地把自己和他人放在一起，比成绩、比工作、比收入、比生活，而这种比较往往是“向下焦虑，向上嫉妒”——看到别人比自己好，就陷入自我否定；看到别人不如自己，也无法获得真正的满足，反而会担心“自己哪天也会落后”。

心理学研究表明，长期的社会比较会引发持续的心理内耗，这种内耗比身体疲惫更消耗能量。因为我们的精力是有限的，当大部分精力都用来关注“别人怎么看”“别人做得怎么样”，留给自己行动的精力就所剩无几了。就像一个人同时拉着好几辆马车，每一辆马车都代表着他人的期待和比较的压力，最终只会因为力不从心而放弃所有努力，选择躺平摆烂——不是不想动，而是实在没有多余的能量去行动，只能用“摆烂”来逃避这种无尽的内耗。

第三个环节，是**“自我边界模糊”导致的行动内驱力缺失**。萨特所说的“他人即地狱”，本质上是“自我被他人吞噬”的困境。很多人之所以会被他人的评价左右，核心是自我边界模糊——我们不知道“我是谁”，不知道自己真正想要什么，只能通过他人的反馈来定义自己。于是，我们的行动不再是为了满足自己的需求，而是为了取悦他人、获得他人的认可。

当行动的内驱力从“自我需求”变成“他人认可”，行动力就会变得极其脆弱。因为他人的认可从来都是不稳定的：今天他们喜欢你这样做，明天可能就否定你；这个人认可你，那个人可能就挑剔你。当我们无法从他人那里获得稳定的认可时，行动的动力就会瞬间消失。更可怕的是，长期为了他人而行动，我们会逐渐忘记自己真正想要什么，甚至失去行动的热情——既然做什么都不是为了自己，那不如不做，躺平摆烂反而成了一种“解脱”。

看到这里，你或许会发现：那些被“他人即地狱”摧毁行动力、最终躺平摆烂的人，本质上不是“懒惰”，而是陷入了**自我价值感缺失、心理内耗严重、自我边界模糊**的三重困境。他们的摆烂，不是主动选择放弃，而是被动的“精神罢工”——当自我被他人的目光牢牢捆绑，当行动的每一步都要承受他人的评判和期待，行动就变成了一种痛苦的负担，而躺平摆烂，是他们对抗这种痛苦、保护自己的唯一方式。

但请记住，“他人即地狱”从来不是不可打破的宿命。萨特在写下这句话的同时，也给出了破解之道：“他人即地狱，也即天堂”——他人可以摧毁我们，也可以成就我们，关键在于我们是否能守住自我的边界，摆脱他人评价的捆绑。改变从来都不是一蹴而就的，但只要我们从细微处入手，慢慢调整，就能重新找回行动力，走出躺平摆烂的困境。

首先，**建立清晰的自我边界，学会“课题分离”**。心理学中的“课题分离”，是破解“他人即地狱”的核心方法——分清什么是自己的课题，什么是他人的课题。他人怎么评价你、怎么看待你，是他人的课题，你无法控制，也无需负责；而你怎么看待自己、怎么行动，是你自己的课题，与他人无关。

比如，你想学习一项新技能，他人说“这没用”，这是他人的课题，你无需因为这句话放弃自己的想法；你努力做好了一件事，他人不认可，这也是他人的课题，你无需因此否定自己的努力。学会把他人的评价“挡在门外”，专注于自己的课题，你会发现，行动的阻力会减少很多——因为你不再需要为了取悦他人而行动，只需要为自己负责。

其次，**停止无意义的社会比较，专注于“自我成长”**。摆脱比较内耗的关键，不是“不去比较”，而是“换一种比较方式”——从“和他人比较”转向“和过去的自己比较”。每天进步一点点，每周完成一个小目标，每月突破一个小瓶颈，当你看到自己的成长，就会获得源源不断的行动力。

同时，学会接纳自己的不完美。每个人都有自己的节奏，有人跑得快，有人跑得慢，不必因为别人比自己优秀就否定自己。接纳自己的普通，允许自己有做得不好的时候，才能减少心理内耗，把更多的精力放在行动上。就像那句话说的：“慢慢来，比较快”，专注于自己的成长，时间会给你最好的答案。

最后，**重建自我价值感，从“小行动”积累成就感**。自我价值感的重建，从来都不是靠他人的认可，而是靠自己的行动。不要一开始就给自己定过高的目标，那样只会因为无法完成而打击自己的信心。不如从身边的小事做起：每天坚持读书半小时，每天运动10分钟，每天完成一件力所能及的小事。

每完成一件小事，就给自己一个肯定；每取得一点进步，就给自己一个鼓励。这些微小的成就感，会像星星一样，慢慢照亮你灰暗的内心，让你重新相信“我能做到”。当自我价值感慢慢重建，你会发现，行动力会自然而然地回来——因为你不再需要靠他人的认可来证明自己，而是从行动本身获得了力量。

其实，“他人即地狱”从来都不是人际关系的真相，而是我们自己把他人的目光，变成了囚禁自己的地狱。那些躺平摆烂的日子，那些失去行动力的瞬间，本质上都是我们在为“模糊的自我边界”“无意义的内耗”“缺失的自我价值感”买单。

请相信，你从来都不是一个人在战斗，也从来都不是“不行”。摆脱他人的捆绑，守住自我的边界，停止内耗，从小行动开始积累力量，你一定会慢慢找回行动力，走出躺平摆烂的困境。毕竟，人生的主角从来都是你自己，他人的目光只是沿途的风景，不该成为你前行的阻碍。

愿你能打破“他人即地狱”的枷锁，找回属于自己的行动力，不躺平、不摆烂，不慌不忙、坚定前行，活成自己喜欢的样子。
